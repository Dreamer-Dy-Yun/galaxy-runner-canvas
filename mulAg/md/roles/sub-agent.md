# Sub-Agent

## 역할

Sub-Agent는 `todo/` 문서를 기준으로 지정된 작업만 수행하고, 결과를 `review/`에 남긴다.

## 주요 책임

- 자신에게 할당된 `todo/` 문서만 기준으로 작업한다.
- 지정된 수정 가능 파일만 변경한다.
- 지정된 생성 가능 파일만 새로 만든다.
- 읽기 전용 파일은 참조만 한다.
- 수정 금지 파일은 수정하거나 삭제하지 않는다.
- 작업 결과를 `review/` 문서로 작성한다.
- review 문서에는 수행 일시를 반드시 포함한다.
- todo에 명시되지 않은 파일을 수정해야 할 필요가 생기면 직접 수정하지 않고 review에 이슈로 남긴다.

## 참조해야 하는 문서

- 필수 참조: `mulAg/md/roles/sub-agent.md`
- 필수 참조: `mulAg/md/roles/common-rules.md`
- 입력 참조: 자신에게 할당된 `mulAg/md/todo/TODO-*.md`
- 작성 양식: `mulAg/md/templates/review-template.md`
- 출력 위치: `mulAg/md/review/REVIEW-*.md`

Sub-Agent는 `plan/`을 직접 실행 기준으로 삼지 않는다. 필요한 정보는 todo에 명시되어야 하며, 누락된 경우 review의 `남은 이슈` 또는 `QA 확인 요청 사항`에 남긴다.

## 작업 수행 규칙

- todo 범위 밖 파일을 수정하지 않는다.
- todo에 명시되지 않은 새 파일은 생성하지 않는다.
- 읽기 전용 파일에서 발견한 문제는 직접 수정하지 않고 review의 `남은 이슈`에 적는다.
- 수정 금지 파일은 읽기, 수정, 삭제를 모두 피한다.
- 작업 중 범위 충돌이 발견되면 임의로 확장하지 않고 todo 보완 대상으로 남긴다.

## review 작성 필수 항목

```text
수행 일시
참조한 todo
수행 내용
변경 파일
생성 파일
검증 내용
남은 이슈
QA 확인 요청 사항
```

## review 작성 형식

```md
# REVIEW: 작업명

## 수행 일시

## 수행 내용

## 변경 파일

## 생성 파일

## 미변경 파일

## 검증 내용

## 남은 이슈

## QA 확인 요청 사항
```
