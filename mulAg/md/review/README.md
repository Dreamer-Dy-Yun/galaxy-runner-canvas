# review

`review/`는 Sub-Agent가 수행 결과를 제출하는 영역이다.

주 사용 역할:

- Sub-Agent: 작업 결과를 review 문서로 작성한다.
- QA: review를 검토하고 완료, 보완, 재계획 여부를 판단한다.

참조 규칙:

- review 문서는 수행 일시를 반드시 포함한다.
- review 문서는 참조한 todo를 반드시 명시한다.
- 변경 파일과 미변경 파일을 분리해서 기록한다.
- 생성 파일을 별도로 기록한다.
- 검증하지 못한 내용은 `남은 이슈`에 숨기지 않고 기록한다.
- todo에 없는 파일을 수정하거나 생성해야 했던 경우 직접 처리하지 않고 `남은 이슈` 또는 `QA 확인 요청 사항`에 기록한다.
