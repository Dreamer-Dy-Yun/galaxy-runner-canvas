# todo

`todo/`는 Sub-Agent가 수행할 작업 단위 문서를 보관하는 영역이다.

주 사용 역할:

- Orchestrator: todo를 작성한다.
- Sub-Agent: 자신에게 할당된 todo만 읽고 수행한다.
- QA: review 검토 시 원본 todo의 완료 기준과 파일 접근 권한을 대조한다.

참조 규칙:

- todo는 반드시 수정 가능 파일, 생성 가능 파일, 읽기 전용 파일, 수정 금지 파일을 명시한다.
- todo는 선행 작업이 필요한 경우 선행 조건을 반드시 명시한다.
- Sub-Agent는 todo에 적힌 수정 가능 파일 밖을 수정하지 않는다.
- Sub-Agent는 todo에 적힌 생성 가능 파일 밖을 새로 만들지 않는다.
- 추가 참조 문서가 필요하면 todo의 `읽기 전용 파일`에 명시한다.
- 동일 파일을 여러 Sub-Agent가 동시에 수정하는 todo는 만들지 않는다.
- 동일 파일 후속 작업은 선행 todo가 `done/`으로 이동한 뒤 새 todo로 다시 정의한다.
