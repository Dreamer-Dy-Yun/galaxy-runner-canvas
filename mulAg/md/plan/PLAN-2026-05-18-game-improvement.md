# GAMEPLAY PROJECT IMPROVEMENT PLAN

작성일: 2026-05-18
최종 갱신: 2026-05-18

## 목표

- Galaxy Runner Canvas의 개선 항목을 멀티 에이전트 방식으로 분리 실행한다.
- 기능 변경 시 책임 경계를 명확히 유지하고, `plan -> todo -> review -> done` 흐름을 준수한다.
- 한 번에 끝나는 “일괄 수정”이 아니라, 검증 가능한 작은 단위로 이관한다.

## 현재 상태 요약

- `mulAg/md` 운영 골격은 실제 실행 가능한 plan/todo/review 문서로 정비되어 있고 `TODO-001~005`까지 분해됨.
- 게임 핵심 로직 개선은 문서상으로 `TODO-001~004`로 분리되었으며, 문서 기준 기준선에서만 추적됨.
- `TODO-001`는 `REVIEW-001` 제출 상태이며, 남은 이슈 3건이 기록됨(브라우저 수동 검증 항목 포함).
- `mulAg/md` 문서 체계의 경계 정비와 교차참조 정합은 `TODO-005`에서 계속 진행 중.

## 실행 방식

1. Orchestrator는 이 Plan을 기준으로 TODO를 생성한다.
2. Sub-Agent는 각 `TODO-*.md`만 수행한다.
3. QA는 `REVIEW-*.md`를 기준으로 기준 충족을 확인한다.
4. 완료 항목은 `done/`으로 이동한다.

- TODO-002: 대기(분해만 완료, 실행 전)
- TODO-003: 대기(분해만 완료, 실행 전)
- TODO-004: 대기(분해만 완료, 실행 전)

## todo 목록

- TODO-001: 엔진 안정성 및 입력/루프 견고화
- TODO-002: 게임플레이 데이터 계약 정합성 정리(무기/아이템/밸런스)
- TODO-003: 특수능력·무기 동작 책임 정합화
- TODO-004: 성능/확장성 하드닝(충돌·투사체·루프 경계 정리)
- TODO-005: 멀티 에이전트 문서 체계 정비(폴더/모듈별 MD 동기화)

## 완료 정의

- 각 TODO가 `실행 결과 + 검증 + 남은 이슈`를 포함한 REVIEW 문서로 제출된다.
- 변경 파일은 각 todo의 `수정 가능 파일` 범위를 벗어나지 않는다.
- 완료 후 TODO 산출물을 `done/`으로 정리한다.
- 리뷰 항목은 `mulAg/md/review/REVIEW-*.md`에 추적 가능해야 한다.
