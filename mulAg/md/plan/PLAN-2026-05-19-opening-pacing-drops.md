# PLAN-2026-05-19-opening-pacing-drops

## 목적

- 게임 초반 적 개체 수를 줄여 플레이어가 무기 차이를 읽을 시간을 준다.
- 적이 화면에 머무르는 시간을 늘려 조준, 회피, 무기 상성 판단을 가능하게 한다.
- 랜덤 시간 기반 아이템 생성을 줄이고, 적 처치 보상으로 아이템 획득 흐름을 옮긴다.

## 적용 내용

- 첫 적 스폰을 즉시 발생시키지 않고 짧게 지연한다.
- 기본 스폰 간격을 늘리고, danger에 따른 간격 감소는 유지한다.
- 적 role별 세로 이동 속도를 낮춰 화면 체류 시간을 늘린다.
- 랜덤 아이템 생성 간격을 늘린다.
- 적 처치 시 아이템 드롭 확률을 적용한다.
- 미드보스와 보스는 아이템을 확정 드롭한다.

## 완료 기준

- 초반 화면에 적이 갑자기 많이 쌓이지 않는다.
- 일반 적이 이전보다 오래 화면에 머문다.
- 필드 아이템은 랜덤 생성보다 처치 보상에서 더 자주 나온다.
- `GAME_CONFIG.items.maxOnField` 제한은 유지된다.
