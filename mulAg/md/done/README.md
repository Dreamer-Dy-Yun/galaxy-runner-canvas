# done

`done/`은 QA가 완료 기준을 만족한다고 판단한 작업 기록을 보관하는 영역이다.

주 사용 역할:

- QA: 완료된 review를 done으로 이동하거나 DONE 문서로 정리한다.

참조 규칙:

- done 처리는 QA만 수행한다.
- DONE 문서는 원본 review와 todo를 추적할 수 있어야 한다.
- done에 들어간 작업은 동일 작업 반복을 막기 위한 기준 자료로 사용한다.
- 파일 수정 권한 위반, 생성 가능 파일 위반, 동일 파일 병렬 수정 흔적이 있는 review는 done으로 이동하지 않는다.
- 선행 조건이 완료되지 않은 작업은 done으로 이동하지 않는다.
